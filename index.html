Héberger les images sur ton GitHub

Facultatif : les images s’affichent déjà automatiquement. Ceci les copie dans ton dépôt pour ne plus dépendre du wiki — en un seul toucher, même depuis l’iPhone.

Comment obtenir le jeton (2 min, une seule fois)
  1. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : « Only select repositories » → ton dépôt du site.
  3. Permissions → Contents : « Read and write ». Génère, copie le jeton et colle-le ici.
